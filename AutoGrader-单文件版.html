    文档类型设置 内置 9 类 · 自定义 0 类

    类型决定评分方向：用数据结构的量表去评计算机网络实验会评错方向（那不是分低，是评错了）。内置 9 类，覆盖计算机专业主要方向（通用编程 / 数据结构与算法 / 操作系统与系统编程 / 计算机网络 / 数据库 / 软件工程与课程设计 / 人工智能与机器学习 / 数字电路与计算机组成 / 通用报告），可改名、改特征词、增删评分方向；工作台与这里双向同步，任一处改动另一边立即可见。点每行右侧的 ▸ 展开特征词与评分方向。

    智能量表 一句话生成 · 按作业自动适配

    换一次作业就要手动调 8 个分值，没人愿意干第二次。这里提供两条入口： 一句话描述你的评分偏好（本地规则引擎离线即可解析，配了 API Key 会自动升级为大模型生成）， 或者按已上传的这批作业自动适配（无需人工标注范文）。 两条入口都只产出建议，点「采纳」才写入下方量表；手动调节始终开放， 手动改过或锁定的维度，任何自动调整都不会覆盖。

    评分量表 总分 100

    量表即「评分准则」：每个维度的得分要点与扣分情形会作为约束下发给模型，让它逐项覆盖、不漏维度。可调整维度名称与分值，总分需为 100。手动改动分值会自动锁定该维度（解锁后自动策略才可调它），锁定列也可自行勾选。
    想整体换成另一类作业的评分方向，对相应类型点「套用为评分准则」——类型与这里的维度双向同步。

    研究分析（进阶）量表诱导 · 信度自检

    以下功能用于教学研究或评分信度验证，日常评分无需展开。展开后可对比范文自动生成量表、检验同一模型多次评分的一致性。

    量表自动诱导 让好报告自己告诉你要点什么

    给已评分的报告标一下「优秀范文」和「对照范文」，点「开始诱导」即可： 系统对比两组，把只有好报告才做到的要点挑出来，并按重要程度分配分值。 评分参数已按教学场景配好，不需要你调。

    评分信度自检 Cronbach's α · Bootstrap CI · Jackknife 敏感度

    自动评分必须回答「这个分数有多可信」。α 衡量各维度是否在测同一件事； 稳定性检验让同一模型对同一份报告连续评阅多次，给出总分的波动区间—— 这直接回答「同一份作业明天再评一遍会不会换个分」。 Jackknife 逐维度剔除，识别「一权独大」的支配维度。

    关于

    技术栈：原生 HTML / CSS / JavaScript，零构建、零依赖，双击 index.html 即可运行；雷达图、热力图与 PDF 导出全部手写。
    评分可解释：每一个得分都附带命中的原文证据片段，教师可逐项复核，避免「黑箱打分」。
    3 套界面主题 + 3 档评语人格（学院派 / 傲娇小天才 / 火力全开）—— 只换表达，不换分数。
    右下角常驻答疑助手：怎么批量导入、这个分为什么这么低、量表怎么调，本地知识库直接答，不联网也能用；配上 API Key 后，知识库答不上来的会转给大模型，并自动带上当前报告的评分上下文。
