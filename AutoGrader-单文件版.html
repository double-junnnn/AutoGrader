    相似度查重 基于 5-gram Jaccard，≥45% 判定为可疑

    至少需要 2 份报告才能进行相似度比对

    量表自动诱导 区分度驱动，而非频次驱动

    教师手写量表最常见的两个偏差：把「人人都写」的东西列为得分点（零区分度，占分却拉不开差距）， 以及分值凭直觉分配。本引擎要求先标注优秀组与对照组范文， 再对每个候选要点计算 Δ = 优秀组命中率 − 对照组命中率，只保留 Δ 高于阈值的要点， 并按 Δ·√支持度 分配分值——区分不出好坏的要素自动出局。

    评分信度自检 Cronbach's α · Bootstrap CI · Jackknife 敏感度

    自动评分必须回答「这个分数有多可信」。α 衡量各维度是否在测同一件事； Bootstrap 通过反复删减 15% 段落重新评分，给出总分的 95% 置信区间； Jackknife 逐维度剔除，识别「一权独大」的支配维度。

    双引擎交叉验证 分歧即信号

    本地启发式偏保守（认关键词不认语义），大模型偏宽松且不稳定。与其盲信其一，不如让两者互相监督。 未配置 API Key 时，第二意见自动退化为重采样基线，依然能暴露「分数是否脆弱」。

    外观与语气 主题 + 评语人格，即时生效

    界面主题只影响观感，不影响任何评分结果；切换后导出 PDF 会跟随当前主题配色。 评语人格决定维度评语与总评的措辞风格——三档人格共用同一套评分口径，换语气不会让分数变。

    关于「傲娇小天才」与「火力全开」：两档人格都内置了硬约束 —— ① 吐槽只针对报告内容（这一段、这组数据、这个结论）， 绝不评价作者本人；② 每句刻薄之后必须跟一条可执行的修改建议；③ 严禁暴力、死亡、血腥、排泄、脏话、歧视类措辞。 用于正式存档时，切回「学院派」即可。

    智能量表 一句话生成 · 按作业自动适配

    换一次作业就要手动调 8 个分值，没人愿意干第二次。这里提供两条入口： 一句话描述你的评分偏好（本地规则引擎离线即可解析，配了 API Key 会自动升级为大模型生成）， 或者按已上传的这批作业自动适配（无需人工标注范文）。 两条入口都只产出建议，点「采纳」才写入下方量表；手动调节始终开放， 手动改过或锁定的维度，任何自动调整都不会覆盖。

    大模型引擎配置 兼容 OpenAI 风格接口

    大模型引擎是可选增强：本地启发式引擎已能完成全部评阅，不配置也能正常使用； 配置后语义理解更强，并解锁「多引擎共识」的真实第二意见。API Key 仅保存在本机浏览器。

    API Key 从哪来：去对应服务商的开放平台注册 → 找「API Keys」页面 → 点「创建」→ 复制那串 sk-…。它只显示一次，复制后立刻粘贴进来。以 DeepSeek 为例：platform.deepseek.com → 左侧「API Keys」→ 创建 API key。
    已验证可用：智谱 GLM（GLM-4.7-Flash 永久免费）、硅基流动（9B 以下模型免费）、DeepSeek、通义千问、Moonshot、OpenAI，以及本地 Ollama（选它会自动填占位 Key，本机需先跑 ollama serve 并设置 OLLAMA_ORIGINS=*）。
    提示：免费额度用尽会返回 402（余额不足），此时换用上面两家免费服务商即可；只要不勾「大模型引擎」，本地引擎完全不受影响。
    若测试连通性报 CORS 错误，说明该端点未允许浏览器跨域直连，需改用服务端代理或本地 Ollama。
