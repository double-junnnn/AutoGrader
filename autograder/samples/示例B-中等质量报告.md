# 排序算法实验报告

## 实验目的
本次实验的目的是了解几种常见的排序算法，通过编写代码实现冒泡排序和快速排序，掌握它们的基本思想。

## 实验环境
使用 Python 语言完成，在 Windows 系统上用 PyCharm 编写运行。

## 实验原理
冒泡排序是比较相邻的元素，如果顺序不对就交换，重复多轮直到有序。快速排序是选一个基准，把小的放左边大的放右边，然后递归处理两边。

## 实验步骤
首先编写冒泡排序的代码，然后编写快速排序的代码，最后用随机生成的数据测试运行时间。

## 核心代码
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

## 实验结果
运行程序后得到结果，冒泡排序比较慢，快速排序比较快。n=1000 时冒泡排序耗时 0.52 s，快速排序耗时 0.008 s。

## 结果分析
从数据可以看出快速排序比冒泡排序快很多，说明分治思想确实能减少比较次数。

## 遇到的问题
一开始写快速排序时递归写错了，程序死循环。后来检查发现是基准元素没有排除在外导致分区不收敛，把基准单独处理后就正常了。
