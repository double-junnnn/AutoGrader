    关于 零依赖 · 本地优先 · 可解释评分

    AutoGrader 面向高校实验报告批改：上传即得逐项核查结果，每一分都附带命中的原文证据， 教师可逐项复核，而不是对着一个说不清来源的数字。

    当前版本要点

    评阅引擎 本地启发式引擎已下线，评分统一交给开源大模型（OpenAI 兼容协议，可选云端免费额度，也可接机房内网 Ollama / vLLM）
    教师终评 AI 分只是初判：总分与任一维度都可覆写，改完自动重算总分，可一键撤销回 AI 原判；导出 PDF 与成绩表并列显示「AI 原判 / 最终得分」
    评分准则 8 个维度可改名称与分值；支持一句话生成、或按这批作业自动适配；手动改过或锁定的维度不会被任何自动调整覆盖
    文档类型 内置 9 类覆盖计算机专业主要方向，可改名、增删特征词与评分方向。类型决定评分方向——用数据结构量表评计算机网络实验不是分低，是评错方向
    相似度查重 5-gram Jaccard 两两比对 + 热力图，≥45% 自动预警；比对范围默认「当前批次内」，可在设置里切换
    可信度自检 证据回查（模型引用的原文查无此句会标红）、信度三件套（Cronbach's α / 多次评阅的分数波动区间 / Jackknife 支配维度）
    离题拦截 小说、散文、乱码这类非报告文档不予评阅（而不是判 0 分——那看起来像评过了），逐条列出判定依据，判错可一键申诉
    答疑助手 右下角常驻：本地知识库直接答，不联网也能用；配了 API Key 后，答不上来的转给大模型，并自动带上当前报告的评分上下文

    技术形态与声明

    原生 HTML / CSS / JavaScript，零构建、零依赖，双击 index.html 即可运行； 雷达图、热力图与 PDF 导出全部手写，不引第三方库。
    报告正文与 API Key 只保存在本机浏览器，仅在主动评阅时才把文本发给所选模型服务商。
    本项目为「粤港澳大湾区 AI Coding 创新大赛」参赛作品。吉祥物「小评审员」为原创形象， 画风借鉴美式动画的通用视觉语言，不使用任何影视剧角色。
